# 🍽️ Ahaaram Multi Cuisine Restaurant

A full-stack web application for a multi-cuisine restaurant that provides an online platform for customers to explore food items, manage their cart, place orders, reserve tables, and interact with restaurant services.

The system also provides customer account management, order history, reservation history, favourite food items, reviews, and an admin dashboard for managing restaurant operations.

---

## 📌 Project Overview

Managing restaurant services manually can be difficult when customers need to view menus, place orders, reserve tables, and track their activities.

The Ahaaram Multi Cuisine Restaurant application helps simplify these restaurant operations through a web-based system.

The application provides:

* Restaurant information
* Multi-cuisine food menu
* Food search and filtering
* Food details
* Shopping cart
* Online food ordering
* Checkout
* Table reservation
* Customer registration and login
* Customer profile
* Order history
* Reservation history
* Favourite food items
* Customer reviews
* Admin dashboard
* Food management
* Order management
* Reservation management
* Customer management
* Review management

## ✨ Key Features

### 🏠 Restaurant Home Page

The home page provides an introduction to Ahaaram Multi Cuisine Restaurant and gives customers quick access to the major restaurant services.

### 🍴 Multi-Cuisine Menu

Customers can browse different food items available in the restaurant.

The menu provides information such as:

* Food name
* Food category
* Price
* Food image
* Food description
* Availability

### 🔍 Food Search and Filtering

Customers can search for food items and filter the menu based on available categories.

This makes it easier to find required food items.

### 📋 Food Details

Customers can open individual food items and view detailed information such as:

* Food name
* Description
* Price
* Category
* Food image
* Availability

### 🛒 Shopping Cart

Customers can add food items to the shopping cart before placing an order.

The cart provides:

* Selected food items
* Quantity
* Price
* Total amount
* Remove item option
* Order summary

### 💳 Checkout

Customers can review their selected items and complete the checkout process.

The checkout page displays the order information and total amount.

### 📦 Online Food Orders

Customers can place food orders through the application.

Order information can be viewed after successful order placement.

### 🪑 Table Reservation

Customers can reserve a table through the online reservation system.

The reservation process includes information such as:

* Customer details
* Reservation date
* Reservation time
* Number of guests
* Reservation details

### 👤 Customer Registration and Login

Customers can create an account and securely log in to access restaurant services.

### 🧑‍💼 Customer Profile

The profile page displays customer-related information and account activities.

### 📦 Order History

Customers can view their previous orders and order-related information.

### 📅 Reservation History

Customers can view their previous table reservations.

### ❤️ Favourite Food Items

Customers can save favourite food items for easier access later.

### ⭐ Customer Reviews

Customers can provide reviews and feedback about their restaurant experience and food items.

### 🛠️ Admin Dashboard

The admin dashboard provides a centralized interface for managing restaurant operations.

The administrator can manage:

* Food items
* Orders
* Reservations
* Customers
* Reviews

### 🍴 Food Management

The admin can:

* Add food items
* Edit food items
* View food items
* Manage food information

### 📦 Order Management

The admin can view and manage customer orders.

### 🪑 Reservation Management

The admin can view and manage customer table reservations.

### 👥 Customer Management

The admin can view customer information and manage customer records.

### ⭐ Review Management

The admin can view customer reviews and manage review information.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/rojasri02/Ahaaram_Multi_Cusine_Restaurant.git
```

### 2. Navigate to the Project Folder

```bash
cd Ahaaram-Multi-Cuisine-Restaurant
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Start the Flask application:

```bash
python app.py
```

The application will run locally.

Open the URL displayed in the terminal in your web browser.
